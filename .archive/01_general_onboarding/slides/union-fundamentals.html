It's just Python. No DSL.

import asyncio
import flyte

env = flyte.TaskEnvironment(
    name="hello_world",
    image=flyte.Image.from_debian_base(python_version=(3, 12)),
)

@env.task(retries=3, cache="auto")     # production features inline
async def predict(x: int) -> int:
    return 2 * x + 5

@env.task
async def main(data: list[int]) -> float:
    xs = await asyncio.gather(*(predict(x) for x in data))
    return sum(xs) / len(xs)           # fan-out = asyncio.gather
  • One decorator: @env.task
  • Loops, if/else, try/except, recursion are the orchestration
  • Parallelism is asyncio.gather, not a special operator
  • Run locally and on the cluster from the same file

flyte run hello.py main --data '[1,2,3]'

⬡ union.aiSolved once, for everyone

Define infra once, reuse it

import flyte

env = flyte.TaskEnvironment(
    name="ml_env",
    image=flyte.Image.from_debian_base()
        .with_pip_packages("pandas", "xgboost"),
    resources=flyte.Resources(
        cpu=(1, 2), memory=("1Gi", "2Gi"), gpu="L4:1"),
    secrets=flyte.Secret(key="WANDB_API_KEY",
                         as_env_var="WANDB_API_KEY"),
    cache="auto",
    reusable=flyte.ReusePolicy(replicas=(1, 4), idle_ttl=300),
)
  • Images built in Python, no Dockerfile required
  • Secrets mounted as env vars or files
  • Resource ranges request → limit autoscaling
  • env.clone_with(...) for CPU/GPU variants
  • task.override(...) per call site
⬡ union.aiTaskEnvironment

Long-running, reusable containers

env = flyte.TaskEnvironment(
    name="warm",
    image=flyte.Image.from_debian_base()
        .with_pip_packages("unionai-reuse"),
    resources=flyte.Resources(cpu=2, memory="8Gi", gpu="L4:1"),
    reusable=flyte.ReusePolicy(
        replicas=(1, 4),    # autoscale 1→4 warm pods
        concurrency=10,     # 10 tasks per replica
        idle_ttl=300),      # spin down when idle
)
# capacity = max_replicas × concurrency = 40 concurrent tasks

Keep a container warm between invocations, so you pay the cold start once, not every call.
